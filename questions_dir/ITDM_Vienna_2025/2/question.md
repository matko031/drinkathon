# Question 2 – Reverse sentence

## Problem

Given a sentence, reverse the order of the words and the order of letters in each word

## Input

* Number of test cases
* Per test case:
  * A single string

## Output

* Per test case:
  * A single string

## Example

```txt
Input:
3
palindrome
this is tricky
reverse words easily
reverse this sentence

Output:
emordnilap
ykcirt si siht
ylisae sdrow esrever
ecnetnes siht esrever
```
